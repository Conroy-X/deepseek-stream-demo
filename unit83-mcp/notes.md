## 核心认知

**MCP 是协议，不是库。** 价值在于工具可被运行时发现、跨 host 复用。
Agent 的能力上限 = 它能用的工具集。

2. 工具异常转结构化错误（不能炸掉调用）
3. 每次调用都留痕（成功失败都记）

## System Prompt 的 4 个作用（今天必须能写出来）

> ⚠️ 2026-10-17 验收修正：下面 2/3/4 条答的是"五段式的段"，不是"System 位置"的作用——
> 它们放 User 也生效（v6 实验：全放 User 合规率照样 100%）。正确答案四条（钩子：人设/宪法/优先级/缓存）：
> ① 恒定人设与规则的容器；② 输出格式的宪法（一次声明管全程）；③ 指令优先级最高（防注入防线）；
> ④ 成本锚点（恒定前缀命中上下文缓存）。完整版见 ../docs/prompt-notes.md 第二节。
> ——保留原始答案作对照，面试前重点复习这题。

1. 设定角色， 让AI回答更为专业

2. few-shot 锁定模型边界

3. 锁定输出格式,  降低模型输出token

4. 给定约束， 提升合规率

## 我自己的话解释「System 和 User 的本质区别」

> 提示：不是"一个在前一个在后"。从**稳定性**、**多轮对话时的处理方式**、**指令优先级**三个角度想。

system主要是： 锁定模型角色， 边界， 提升回答的专业性， 指令优先级最高

user Prompt 主要是待执行的任务

## 一、评测回答三个问题

| 问题 | 指标 |
| --- | --- |
| 检索找对了吗？ | Recall@K |

```
        │
   任何指标掉了 → 停下来查
```

## 五、面试追问

**Q: 为什么每次改 prompt 都要跑评测？**
→ prompt 是模型行为的隐形参数，改一个字可能让某个类别的答案变差。
离线评测集保证「不退化」，线上抽检发现「离线没覆盖的问题」。

**Q: 评测集怎么来？**
→ 从真实日志采样 + 人工标金标准；覆盖三类：正常问答、拒答、难例（改写/多跳）。

**Q: 三个指标能合并成一个吗？**
→ 不建议。不同指标对应不同失败模式，合并会掩盖「检索好但答案差」这类问题。
分开看，才能定位问题出在哪一层。

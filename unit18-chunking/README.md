## 实测（本单元最重要的数据）

内置语料 6 个话题、49 句、约 1700 字，12 道固定问题，`size=160 / overlap=30 / top_k=3`：

| 策略 | 块数 | 平均字数 | 命中 | recall@3 |
| --- | ---: | ---: | ---: | ---: |
| fixed | 10 | — | 11/12 | **0.92** |
| recursive | 10 | — | 12/12 | **1.00** |
| semantic | 18 | — | 12/12 | 1.00 |

fixed 丢的那一题，是因为句子被从中间切开：「退款多久到账」的答案跨在
两块的交界上，两块各带半句，谁都不够像。

### 参数扫描（`uv run python sweep.py`，可复现）

**recall@3**（overlap = size/5）：

| 策略 | size=100 | size=160 | size=240 | size=400 | size=800 |
| --- | ---: | ---: | ---: | ---: | ---: |
| fixed | 0.92（16 块） | 0.92（10 块） | 1.00（7 块） | 1.00（4 块） | 1.00（2 块） |
| recursive | 1.00（20 块） | 1.00（10 块） | 1.00（6 块） | 1.00（4 块） | 1.00（2 块） |
| semantic | 1.00（20 块） | 1.00（18 块） | 0.92（15 块） | 0.92（15 块） | 0.92（15 块） |

**recall@1**（更严格，但已经开始抖）：

| 策略 | size=100 | size=160 | size=240 | size=400 | size=800 |
| --- | ---: | ---: | ---: | ---: | ---: |
| fixed | 0.67 | 0.83 | 0.75 | 0.83 | 0.92 |
| recursive | 0.83 | 0.75 | 0.67 | 1.00 | 0.92 |
| semantic | 0.67 | 0.75 | 0.67 | 0.67 | 0.67 |

**结论要说准，别编故事**：

1. **"size 越大 recall 越差"在这份语料上不成立**。recall@3 只在 `size=100/160` 的 fixed 上掉一题
   （答案被切断，块太小装不下），`240` 之后一直是 1.00 —— 因为语料只有 1238 字，
   块大到 800 时整篇只剩 2 块，前 3 名必然命中，指标已经**饱和**、失去区分度。
2. **semantic 的块数由阈值决定，几乎不受 size 影响**（15–18 块），所以它的曲线是平的。
   它掉的那一题出现在 `240` 以后，原因是块数减少时句子被并进更大的组。
3. **recall@1 在 0.67–0.92 之间非单调抖动** —— 12 道题里差 1 题就是 8.3 个百分点，
   这已经在噪声范围里。**用 12 道题做参数微调是不可靠的**，只能用来发现"某个策略有严重问题"。

> 想真正测出 size 的影响，需要：语料 ≥ 5 万字、题目 ≥ 50 道、并加入同义改写和无答案（该拒答）两类题。
> 把它写下来，比硬凑一个"块越大越差"的结论有用 —— 后者是编的，一上真实数据就翻车。

## 三个实现细节（都是坑）

**1. `overlap >= size` 必须直接报错**

不是保守，是死循环：`step = size - overlap = 0`，切分永远前进不了。

**2. 覆盖率要用"去重"算法**

`sum(len(chunk))` 在有 overlap 时必然大于原文，看不出是否丢字。
正确做法是打一个字符掩码，看原文每个位置有没有被至少一块覆盖：

```python
mask = bytearray(total)
for c in chunks:
    for i in range(c.start, c.end):
        mask[i] = 1
return sum(mask) / total      # 必须是 1.0
```

**3. 小标题不能孤立在块尾**

凑长度时，`费用报销与差旅` 这种短标题会刚好塞进上一块的末尾，
于是它挂在一堆年假条款后面 —— 检索时它谁也不代表。
所以切分前要先把标题粘到它的正文上，且给正文留出 `size - 标题长度` 的额度。

## 语义切分的阈值为什么是 0.05

因为**阈值跟模型绑定**。本地哈希向量下，本单元 49 句的相邻相似度：

```
中位数 0.096 · 最大 0.381
```

阈值取 0.3 会把 49 句切成 48 块（等于逐句切），取 0.05 才是 18 块。
换真语义模型（中位数通常 0.4 以上）必须重新标定 —— 抄别人的 0.8 等于没做。

> 自检会打印这行数字，`uv run python main.py` 自己看一眼。

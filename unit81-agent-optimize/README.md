# Unit 81 · Agent 优化

> Agent 跑飞的两个典型问题：无限循环、重复调用。

## 一、本单元做什么

步数预算 + 工具去重，防 Agent 死循环和重复调工具。

## 二、要点

- 步数预算强制终止
- 同参数工具调用去重
- 预算外不再执行

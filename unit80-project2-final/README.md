## 二、服务设计

```
用户问 → 字符级检索（char overlap） → 命中阈值 0.4？ → 有：摘抄 + [1] 引用
                                                    → 无：固定拒答
```

- 检索用字符级重叠（不依赖 API，离线可测）
- 拒答是**设计好的行为**：资料里没有就直说，不编
- 引用带 `source` 和 `page`，方便回原文核对

## 三、录 Demo 脚本（30 秒版）

按顺序操作，每一步都说一句「这证明了什么」：

1. 打开 `http://127.0.0.1:8080/` → 说：「这是企业知识库问答界面」
2. 输入「退款多久到账」→ 说：「答案来自知识库，带 [1] 引用和原文页码」
3. 输入「今天天气怎么样」→ 说：「知识库里没有，系统明确拒答，不编造」
4. 打开 `/docs` → 说：「接口有完整的 OpenAPI 文档」
5. 总结：「检索、引用、拒答、可观测，四个要素齐了」

## 六、面试追问

**Q: 这个项目最核心的工程决策是什么？**
→ 阈值前置：检索分数不够就不让生成。这是「不编造」唯一可靠的实现位置。

**Q: 怎么证明它「不编」？**
→ 拒答是常量话术，自检直接断言；有依据的答案逐字来自知识库（可逐字比对）。

**Q: 下一步优化方向？**
→ 混合检索（Unit 76）、重排（Unit 77）、评测集（Unit 78）都是现成的零件。

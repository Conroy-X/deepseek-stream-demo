## 核心认知

**token 是模型看到的最小单位**——不是字符也不是单词，是训练出来的高频片段。
BPE 从字符出发反复合并高频相邻对。

## 计费公式

```
成本 = input_tokens/1M × 输入单价 + output_tokens/1M × 输出单价
```

output 单价通常更高：生成是逐 token 的，不能并行。
